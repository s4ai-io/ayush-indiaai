Evaluation Methodology
Ground Truth Generation:
Manual Annotation: Manual, character-perfect extraction of all fields as Ground Truth
Testing Methodology:
Short Fields : <=2 words and <30 characters
Character similarity: 1- Levenshtein Distance
Long Fields: Hybrid Score
0.3* Char. sim. + 0.7 * Token Similarity (Jaccard)
Correctness Threshold for accuracy : 0.8
Hallucination Detection for Disciplinary cases:
Model as a Jury approach using MiniCheck library with on-prem flan-t5-large model
https://www.cs.cmu.edu/~wcohen/postscript/kdd-2003-match-ws.pdf .. 

Document Agnosticism:  Whether it’s an APAR (Performance Report) or a Name Change Gazette, the logic is entirely contained within the JSON fields definition.
Atomic Field Definitions:  Each field has validation rules - data types (text, date, table), & extraction (descriptions).
Advanced Conditional Intelligence
Variable Injection: The use of placeholders like ${given} helps us inject runtime variables into the configuration - e.g Name Change case
Execution Flow Control: The conditional_params block (e.g., fetch: "old_name") allows the system to trigger specific extraction paths based on the document's content.
Feature Toggling: Enables per-document customization of advanced outputs like LLM summaries or folder-level analysis without global code changes.
Zero-Redeployment Onboarding: New document types are "programmed" via JSON updates, eliminating the need for engine restarts or code pushes.
